⚠️ Notice for Microsoft Edge & Chrome Users:
You are currently viewing this file via file:///. Due to browser security restrictions, Edge and Chrome strictly prohibit scripts on external websites (like TMDB) from opening file:// URLs. Bookmarklets created with a file:// URL will fail silently.

To make the bookmarklet work in Edge:
  1. Run python3 -m http.server 8000 in your terminal.
  2. Set the Target URL below to http://localhost:8000/tmdb-to-markdown.html.

📖 How to Set Up Your Bookmarklet

  • Option 1 (Drag & Drop): Drag the purple Locus TMDB Reviewer button above directly onto your browser's Bookmarks Bar.
  • Option 2 (Manual / Safari): Click Copy Bookmarklet Code. Create a new bookmark for any page, edit the bookmark, and paste the code into the URL field.
💻 Serving from a Local Folder (file:///) vs. Web Server:
If you open this directly from a folder (e.g. file:///Users/.../tmdb-to-markdown.html), note that some browsers (like Safari and Chrome) restrict scripts on themoviedb.org from opening local file:/// URLs due to sandbox security.

💡 Recommended: Run a lightweight local server in this directory:
python3 -m http.server 8000
Then open http://localhost:8000/tmdb-to-markdown.html, click Auto-Detect above, and save. The bookmarklet will work seamlessly across all browsers!
